Google Calendar Guide
✅ How it works now — Calendar Events (not Tasks)
Each scheduled work day on your task opens a pre-filled Google Calendar event in a new tab. Events appear as colored blocks on each day — exactly like the existing events in your calendar. Just click Save in each tab.
1
Add a task and set Scheduled Work Days (e.g. Jun 10, Jun 17, Jun 24). Check "Auto-open Google Calendar after saving."
2
Click Save Task. One Google Calendar tab opens per work day, each pre-filled with the event title (e.g. Email Management [CE]), time 9AM–10AM, and full task details.
3
In each Google Calendar tab, review the event and click Save (blue button). The event appears as a colored block on that day — same as your existing CE/SIT events.
4
If you have multiple work days, tabs open 0.6 seconds apart to avoid browser pop-up blocking. Allow pop-ups from this app for best results.
5
You can also click "Add to Calendar" on any task card at any time to re-open the event creation tabs for that task.
6
Pop-up blocked? Click the pop-up blocked icon in your browser address bar and select "Always allow pop-ups from this page."
